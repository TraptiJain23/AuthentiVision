MobileNetV2 Transfer Learning Pipeline

MobileNetV2 uses depthwise separable convolutions with inverted residuals and linear bottlenecks. This lightweight, highly efficient architecture delivers fast inference suitable for high-throughput marketing campaign asset auditing while maintaining superior accuracy.

Stage Layer Name / Operation Output Dimension
Input input_1 (RGB image) (None, 224, 224, 3)
Normalization preprocess_input ([-1, 1]) (None, 224, 224, 3)
Backbone 16 Inverted Residual Bottlenecks (None, 7, 7, 320)
Target Conv out_relu (Conv_1 + ReLU6) (None, 7, 7, 1280)
Pooling GlobalAveragePooling2D (None, 1280)
Regularization Dropout(0.3) (None, 1280)
Classification Head Dense(1, Sigmoid) (P(AI-Generated)) (None, 1)
Grad-CAM Explainable AI Formulation

Gradient-weighted Class Activation Mapping (Grad-CAM) uses the gradients of any target concept flowing into the final convolutional layer to produce a coarse localization map highlighting important regions.

1. Neuron Importance Weights (\(\alpha_k^c\)):

Computed via global average pooling of gradients with respect to feature activation maps \(A^k\):

αkc = (1 / Z) Σi Σj (∂ yc / ∂ Ai,jk)
2. Heatmap Aggregation & ReLU:

Weighted linear combination filtered by ReLU to keep only features that positively correlate with the target class:

LGrad-CAMc = ReLU( Σk αkc Ak )
Model Training & Fine-Tuning CLI Guide

To train AuthentiVision on the standard CIFAKE (60,000 Real / 60,000 AI) or GenImage datasets:

# 1. Phase 1: Train classification head (Backbone frozen, saves models/phase1_mobilenetv2.keras)
python src/train.py --phase 1 --data_dir "C:\path\to\cifake" --epochs 5 --batch_size 32

# 2. Phase 2: Fine-tune upper backbone layers (Loads Phase 1 model, saves models/mobilenetv2_authentivision.keras)
python src/train.py --phase 2 --data_dir "C:\path\to\cifake" --epochs 5 --batch_size 32
Phase 1: Feature Extraction
Trains only dense classification head while freezing MobileNetV2 base weights at lr = 1e-4.
Phase 2: Fine-Tuning
Unfreezes upper residual blocks (block 14+) at lower learning rate (lr = 1e-5) to adapt to generative diffusion artifacts.
Model Persistence
Saves finalized model to models/mobilenetv2_authentivision.keras for automatic hot-reloading in the Flask dashboard.
